# 🎨 Адмін Панель Art Gallery

## 📋 Огляд

Адмін панель для Art Gallery - це потужний інструмент для управління галереєю, який дозволяє адміністраторам контролювати всі аспекти бізнесу.

## 🚀 Функціонал

### 📊 Dashboard (Головна сторінка)
- **Статистика продажів**: Загальна кількість фотографій, покупок, замовлень
- **Фінансова аналітика**: Загальний та місячний дохід
- **Останні покупки**: Список останніх 5 покупок з деталями
- **Популярні фотографії**: Топ-5 найпопулярніших фотографій
- **Статистика по статусах**: Розподіл покупок за статусами
- **Дохід по місяцях**: Графік доходів за останні місяці

### 💰 Управління покупками фотографій
- **Перегляд всіх покупок**: Повний список покупок з деталями
- **Підтвердження платежів**: Можливість підтвердити оплату вручну
- **Статуси покупок**: PENDING, COMPLETED, FAILED, EXPIRED
- **Детальна інформація**: Email клієнта, сума, дата, фото

### 🖼️ Управління замовленнями картин
- **Список замовлень**: Всі замовлення на картини
- **Зміна статусів**: NEW, PROCESSING, COMPLETED, CANCELLED
- **Контактна інформація**: Ім'я, email, телефон клієнта
- **Автоматичні email**: Повідомлення про зміну статусу

### 📈 Аналітика
- **Статистика продажів**: По періодах (тиждень, місяць, рік)
- **Популярність контенту**: Аналіз найбільш продаваних фотографій
- **Email статистика**: Аналіз клієнтів по доменах

## 🛠️ Технічна реалізація

### Backend (Spring Boot)
- **AdminController**: REST API для адмін функцій
- **AdminService**: Бізнес-логіка для аналітики
- **Розширені сервіси**: Додаткові методи в існуючих сервісах

### Frontend (React)
- **AdminPanel.js**: Основний компонент адмін панелі
- **AdminPanel.css**: Сучасний дизайн з градієнтами
- **Responsive Design**: Адаптивний дизайн для всіх пристроїв

## 📱 Інтерфейс

### Дизайн
- **Сучасний UI**: Градієнтний фон, картки з тінями
- **Інтуїтивна навігація**: Табы для різних розділів
- **Кольорові статуси**: Візуальне розрізнення статусів
- **Анімації**: Плавні переходи та hover ефекти

### Розділи
1. **Dashboard**: Загальна статистика та аналітика
2. **Photo Purchases**: Управління покупками фотографій
3. **Artwork Orders**: Управління замовленнями картин

## 🔧 API Endpoints

### Dashboard
- `GET /api/admin/dashboard` - Отримання статистики
- `GET /api/admin/sales/stats?period=month` - Статистика продажів
- `GET /api/admin/photos/popular` - Популярні фотографії
- `GET /api/admin/analytics/email-stats` - Email статистика

### Purchases
- `GET /api/admin/purchases` - Всі покупки
- `POST /api/admin/purchases/{id}/confirm` - Підтвердження платежу

### Orders
- `GET /api/admin/orders` - Всі замовлення
- `PUT /api/admin/orders/{id}/status?status=COMPLETED` - Зміна статусу

## 🚀 Запуск

### Backend
```bash
./mvnw spring-boot:run
```

### Frontend
```bash
cd frontend
npm start
```

### Доступ до адмін панелі
Відкрийте браузер і перейдіть на: `http://localhost:3000/admin`

## 📊 Приклади використання

### Підтвердження платежу
1. Перейдіть в розділ "Photo Purchases"
2. Знайдіть покупку зі статусом "PENDING"
3. Натисніть "Confirm Payment"
4. Система автоматично відправить email з посиланням для скачування

### Зміна статусу замовлення
1. Перейдіть в розділ "Artwork Orders"
2. Виберіть новий статус з випадаючого списку
3. Система автоматично відправить email клієнту

### Перегляд статистики
1. На головній сторінці Dashboard подивіться загальну статистику
2. Використовуйте різні періоди для аналізу продажів
3. Аналізуйте популярність фотографій
