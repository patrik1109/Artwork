# Налаштування Stripe для Art Gallery

## Що таке Stripe?

Stripe - це платіжна система, яка дозволяє приймати платежі онлайн. Вона підтримує кредитні картки, дебетові картки та інші методи оплати.

## Кроки для налаштування:

### 1. Створення акаунту Stripe

1. Перейдіть на [stripe.com](https://stripe.com)
2. Натисніть "Start now" або "Sign up"
3. Заповніть форму реєстрації
4. Підтвердіть email

### 2. Отримання тестових ключів

1. Увійдіть в [Dashboard Stripe](https://dashboard.stripe.com)
2. Переключіться в тестовий режим (toggle "Test mode" вгорі)
3. Перейдіть в розділ "Developers" → "API keys"
4. Скопіюйте:
   - **Publishable key** (починається з `pk_test_`)
   - **Secret key** (починається з `sk_test_`)

### 3. Налаштування в додатку

1. Відкрийте файл `src/main/resources/application.properties`
2. Замініть плейсхолдери на ваші ключі:

```properties
# Stripe configuration
stripe.secret-key=sk_test_YOUR_SECRET_KEY_HERE
stripe.publishable-key=pk_test_YOUR_PUBLISHABLE_KEY_HERE
```

### 4. Тестові картки

Для тестування використовуйте ці тестові картки:

#### Успішні платежі:
- **Visa**: `4242424242424242`
- **Mastercard**: `5555555555554444`
- **American Express**: `378282246310005`

#### Неуспішні платежі:
- **Відхилена картка**: `4000000000000002`
- **Недостатньо коштів**: `4000000000009995`
- **Застаріла картка**: `4000000000000069`

**Для всіх тестових карток:**
- **CVV**: будь-які 3 цифри (наприклад, `123`)
- **Дата закінчення**: будь-яка майбутня дата (наприклад, `12/25`)

### 5. Запуск додатку

1. Перезапустіть Spring Boot додаток
2. Перезапустіть React додаток
3. Спробуйте купити фото з тестовою карткою

## Як це працює:

1. **Користувач** натискає "Buy & Download" на фото
2. **Frontend** створює платіжний інтент через API
3. **Stripe** повертає client secret
4. **Користувач** вводить дані картки
5. **Stripe** обробляє платіж
6. **Backend** підтверджує платіж і створює покупку
7. **Email** відправляється з посиланням для скачування

## Безпека:

- ✅ Секретний ключ зберігається тільки на сервері
- ✅ Публічний ключ безпечно передається на клієнт
- ✅ Всі платежі обробляються через Stripe
- ✅ Дані карток не зберігаються в нашій базі

## Перехід на продакшн:

Коли будете готові до реальних платежів:

1. Переключіться в "Live mode" в Stripe Dashboard
2. Отримайте live ключі
3. Оновіть `application.properties`
4. Перевірте всі налаштування безпеки
