# Платне скачування фотографій - Інструкція

## Огляд функціоналу

Реалізовано систему платного скачування фотографій з наступними можливостями:

### Основні функції:
1. **Платні та безкоштовні фотографії** - кожна фотографія може мати ціну або бути безкоштовною
2. **Процес покупки** - користувач може купити фотографію через веб-інтерфейс
3. **Безпечне скачування** - після оплати генерується тимчасовий токен для скачування
4. **Відстеження покупок** - користувач може переглядати свої покупки
5. **Email повідомлення** - автоматична відправка підтверджень та посилань для скачування

## Структура бази даних

### Оновлена таблиця `photo`:
- `price` (DECIMAL) - ціна фотографії (0.00 = безкоштовна)
- `download_url` (VARCHAR) - URL для скачування високоякісної версії

### Нова таблиця `photo_purchases`:
- `id` - унікальний ідентифікатор покупки
- `photo_id` - посилання на фотографію
- `customer_email` - email покупця
- `amount_paid` - сума платежу
- `purchase_date` - дата покупки
- `transaction_id` - унікальний ID транзакції
- `download_token` - токен для безпечного скачування
- `token_expiry` - термін дії токена (7 днів)
- `status` - статус покупки (PENDING, COMPLETED, FAILED, EXPIRED)

## API Endpoints

### Покупки фотографій:
- `POST /api/photo-purchases/purchase` - створити нову покупку
- `POST /api/photo-purchases/confirm-payment` - підтвердити оплату
- `GET /api/photo-purchases/download` - отримати посилання для скачування
- `GET /api/photo-purchases/user/{email}` - отримати покупки користувача
- `GET /api/photo-purchases/can-download` - перевірити можливість скачування

## Процес роботи

### 1. Покупка фотографії:
1. Користувач натискає "Buy & Download" на платній фотографії
2. Відкривається модальне вікно з формою покупки
3. Користувач вводить email та вибирає метод оплати
4. Створюється запис покупки зі статусом PENDING
5. Відправляється email з підтвердженням

### 2. Підтвердження оплати:
1. Адміністратор підтверджує оплату через API
2. Статус змінюється на COMPLETED
3. Генерується download_token з терміном дії 7 днів
4. Відправляється email з посиланням для скачування

### 3. Скачування:
1. Користувач переходить за посиланням з email
2. Система перевіряє валідність токена
3. Якщо токен валідний - надається доступ до скачування
4. Після закінчення терміну дії токен стає неактивним

- Показує статус кожної покупки

## Безпека

### Токени скачування:
- Генеруються автоматично після підтвердження оплати
- Мають обмежений термін дії (7 днів)
- Унікальні для кожної покупки
- Автоматично стають неактивними після закінчення терміну

### Валідація:
- Перевірка email адреси
- Валідація ціни фотографії
- Перевірка статусу покупки перед скачуванням
